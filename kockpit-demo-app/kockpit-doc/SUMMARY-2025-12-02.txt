                        FONCTIONNALITES DE LA DEMO
================================================================================

### API Products (CRUD complet)
----------------------------------------------------------------------------
GET    /api/products          Liste tous les produits
GET    /api/products/{id}     Récupère un produit
POST   /api/products          Crée un produit
PUT    /api/products/{id}     Modifie un produit
DELETE /api/products/{id}     Supprime un produit

Audit automatique: CREATE_PRODUCT, UPDATE_PRODUCT, DELETE_PRODUCT, etc.


### API Orders (Cycle de vie complet)
----------------------------------------------------------------------------
GET    /api/orders                Liste toutes les commandes
GET    /api/orders/{id}           Récupère une commande
POST   /api/orders                Crée une commande
POST   /api/orders/{id}/ship      Expédie une commande
POST   /api/orders/{id}/deliver   Livre une commande
POST   /api/orders/{id}/cancel    Annule une commande

Audit automatique: CREATE_ORDER, SHIP_ORDER, DELIVER_ORDER, CANCEL_ORDER


### Stockage In-Memory
----------------------------------------------------------------------------
- ConcurrentHashMap pour Products
- ConcurrentHashMap pour Orders
- Pas de base de données (demo simple)
- Données perdues au redémarrage


### Configuration Kockpit SDK
----------------------------------------------------------------------------
kockpit:
  sdk:
    domain: demo
    env: local
    appId: demo-app
    enabled: true
  audit:
    backend:
      url: http://localhost:8080/backend/api
      username: user
      password: password


================================================================================
                        PROBLEME IDENTIFIE
================================================================================

### Erreur de Compilation dans kockpit-audit-annotation
----------------------------------------------------------------------------

Symptôme:
  [ERROR] cannot find symbol: variable log
  [ERROR] location: class AuditAttributesAnnotationProcessor
  [ERROR] location: class AuditCommandLineRunnerAspect

Cause:
  Les annotations @Slf4j (Lombok) ne sont pas traitées correctement lors
  de la compilation Maven du module kockpit-audit-annotation.

Impact:
  ❌ Impossible de compiler l'application demo
  ❌ Les dépendances kockpit ne peuvent pas être installées dans .m2

Workarounds documentés:
  1. Utiliser des JARs pré-compilés d'un repository Maven
  2. Fixer les classes avec log explicite au lieu de @Slf4j
  3. Simplifier la demo pour audit manuel sans annotations
