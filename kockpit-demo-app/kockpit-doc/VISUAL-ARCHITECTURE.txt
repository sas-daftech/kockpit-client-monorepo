================================================================================
                        FLUX DE REQUETE AUDIT
================================================================================

1. Client                    curl -u user:password /rcu/local/audits/_search
                                         |
                                         v
2. Spring Security           Valide credentials (Basic Auth)
                                         |
                                         v
3. SearchApi                 Extrait: domain=rcu, env=local, start=0, size=50
                                         |
                                         v
4. SearchService             Construit criteres de recherche
                                         |
                                         v
5. OpensearchRepository      Genere requete DSL OpenSearch
                                         |
                                         v
6. OpenSearch                Execute recherche sur index "kockpit-audit"
                                         |
                                         v
7. OpensearchRepository      Transforme hits en objets Java
                                         |
                                         v
8. SearchService             Construit objet Page (items + total)
                                         |
                                         v
9. SearchApi                 Serialise en JSON
                                         |
                                         v
10. Client                   Recoit: {"size":50, "items":[...], "total":156}

================================================================================
                        MULTI-TENANCY STRUCTURE
================================================================================

                        URL Path Structure
                        ------------------

                /{domain}/{env}/{resource}
                    |       |        |
                    |       |        +--- Resource (audits, config, etc.)
                    |       |
                    |       +------------ Environment (local, dev, prod)
                    |
                    +-------------------- Domain (rcu, payment, billing)


Exemples:
    /rcu/local/audits        -> Domain: rcu,     Env: local
    /payment/prod/audits     -> Domain: payment, Env: prod
    /billing/staging/audits  -> Domain: billing, Env: staging


Isolation des donnees:
    - Index OpenSearch: {domain}-{env}-audits
    - Filesystem: /storage/{domain}/{env}/
    - Azure Container: {domain}-{env}

================================================================================
                        OPENSEARCH INDEX STRUCTURE
================================================================================

Index: kockpit-audit
    |
    +-- Mappings
    |     |
    |     +-- id           : keyword
    |     +-- timestamp    : date
    |     +-- domain       : keyword
    |     +-- env          : keyword
    |     +-- user         : keyword
    |     +-- action       : keyword
    |     +-- ip_address   : ip
    |     +-- user_agent   : text
    |     +-- details      : object
    |
    +-- Settings
          |
          +-- number_of_shards: 1
          +-- number_of_replicas: 1


Requete DSL exemple:
    {
      "query": {
        "bool": {
          "must": [
            {"term": {"domain": "rcu"}},
            {"term": {"env": "local"}},
            {"term": {"user": "john.doe"}}
          ]
        }
      },
      "sort": [{"timestamp": {"order": "desc"}}],
      "from": 0,
      "size": 50
    }
