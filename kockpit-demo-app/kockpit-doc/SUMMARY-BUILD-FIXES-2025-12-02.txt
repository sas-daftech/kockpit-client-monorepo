                              CONTEXTE

Le projet Kockpit ne pouvait pas être compilé à cause de plusieurs problèmes:
1. Utilisation de Java 25 au lieu de Java 17
2. Maven Compiler Plugin ne traitait pas les annotations Lombok
3. Dépendances Lombok manquantes dans certains modules

Ces problèmes empêchaient complètement le build du projet.

================================================================================
                         CONNAISSANCES ACQUISES
================================================================================

TECHNIQUE:
  - Maven Compiler Plugin 3.13.0 nécessite annotationProcessorPaths explicite
  - Lombok doit être en scope provided (optimisation)
  - Java 17 est obligatoire pour Spring Boot 3.4.3
  - Lombok 1.18.36 incompatible avec Java 25

ARCHITECTURE:
  - Projet multi-modules (57 modules)
  - Architecture hexagonale (Ports & Adapters)
  - 3 composants principaux:
    * kockpit-audit (audit automatique)
    * kockpit-rules (moteur de règles)
    * kockpit-backends (APIs REST)

PROCESS:

                         COMMANDES CLÉS
================================================================================

Build complet:
  JAVA_HOME=/path/to/java-17 mvn clean install -DskipTests

Vérifier Java:
  java -version

Lister Java installés (SDKMAN):
  ls ~/.sdkman/candidates/java/

Démarrer OpenSearch:
  cd /path/to/opensearch && docker compose up -d

Démarrer backend:
  cd kockpit-backends/kockpit-backend-application
  JAVA_HOME=/path/to/java-17 mvn spring-boot:run \
    -Dspring-boot.run.profiles=local,opensearch,filesystem

Tester l'API:
  curl -u user:password \
    http://localhost:8080/backend/api/rcu/local/audits/_search
