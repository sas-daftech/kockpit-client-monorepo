                         GLOSSAIRE
================================================================================

API         : Application Programming Interface
REST        : Representational State Transfer
HTTP        : Hypertext Transfer Protocol
JSON        : JavaScript Object Notation
CRUD        : Create, Read, Update, Delete
DTO         : Data Transfer Object
JVM         : Java Virtual Machine
JAR         : Java Archive
POM         : Project Object Model (Maven)
YAML        : YAML Ain't Markup Language
CORS        : Cross-Origin Resource Sharing
CSRF        : Cross-Site Request Forgery
JWT         : JSON Web Token
OAuth       : Open Authorization
TLS/SSL     : Transport Layer Security / Secure Sockets Layer
URL         : Uniform Resource Locator
UUID        : Universally Unique Identifier
HA          : High Availability
SLA         : Service Level Agreement


Termes specifiques Kockpit:
  Audit       : Enregistrement d'une action utilisateur
  Domain      : Domaine metier (ex: rcu, payment)
  Env         : Environnement (local, dev, prod)
  Manifest    : Ensemble de configurations groupees
  Feature Flag: Activation/desactivation dynamique de fonctionnalite
  Adapter     : Implementation concrete d'une interface

                         CONVENTIONS
================================================================================

Notation des endpoints:
  GET /path          : Endpoint GET
  POST /path         : Endpoint POST
  {param}            : Parametre path variable
  ?param=value       : Parametre query string

Notation du code:
  ClassName          : Classe Java
  methodName()       : Methode Java
  CONSTANT           : Constante
  variable           : Variable
  package.name       : Package Java

Parametres:
  (required)         : Parametre obligatoire
  (optional)         : Parametre optionnel
  (default: X)       : Valeur par defaut
