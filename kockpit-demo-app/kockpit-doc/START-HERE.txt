================================================================================
                         PROBLÈMES FRÉQUENTS
================================================================================

ERREUR: "BUILD FAILURE" lors du mvn install
--------------------------------------------
Cause probable: Mauvaise version de Java

Solution:
  1. Vérifier: java -version
  2. Si pas Java 21:
     $ JAVA_HOME=/path/to/java-21 mvn clean install -DskipTests

→ Détails: BUILD-TROUBLESHOOTING.txt


ERREUR: "package lombok does not exist"
----------------------------------------
Cause: Dépendance Lombok manquante dans un module

Solution: Déjà corrigée dans le code source

Si ça persiste:
  $ mvn clean install -U -DskipTests

→ Détails: BUILD-TROUBLESHOOTING.txt


ERREUR: L'application ne démarre pas
-------------------------------------
Cause probable: OpenSearch pas démarré

Solution:
  $ cd /path/to/opensearch
  $ docker compose up -d

→ Détails: QUICK-START.txt (Section Troubleshooting)


ERREUR: 401 Unauthorized sur les APIs
--------------------------------------
Cause: Authentification Basic Auth manquante

Solution:
  $ curl -u user:password http://localhost:8080/backend/api/...

→ Détails: API-REFERENCE.txt (Section 1: Authentification)

================================================================================
                         COMMANDES ESSENTIELLES
================================================================================

Build complet du projet:
  $ JAVA_HOME=/path/to/java-21 mvn clean install -DskipTests

Démarrer OpenSearch:
  $ cd /path/to/opensearch
  $ docker compose up -d

Démarrer le backend:
  $ cd kockpit-backends/kockpit-backend-application
  $ JAVA_HOME=/path/to/java-21 mvn spring-boot:run \
      -Dspring-boot.run.profiles=local,opensearch,filesystem

Tester l'API:
  $ curl -u user:password \
      http://localhost:8080/backend/api/rcu/local/audits/_search

Vérifier la santé:
  $ curl http://localhost:8080/backend/actuator/health
